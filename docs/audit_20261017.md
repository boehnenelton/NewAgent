## Reviewed, no change needed
- **Performance:** import 176 ms, `WebAgentTerminal` init 13 ms, `assemble_bubble` 0.7 ms/call (mtime-cached). Nothing worth optimizing; no change made.
- **Key/secret handling:** `config/keys*.bejson` and `config.json` are already mode 600; secrets are masked/redacted at source and at log sinks (pkg120). Provider URLs in `engine_rest` are fixed, not model-controlled (bandit B310 false positives).
- **Bandit B311/B105/B603/B607/B404:** `random` used only for jitter/selection; `'4'` flagged as a password is a version-like string; `find`/`fd` invoked with list args (no shell).
- **Swallowed exceptions (B110/B112):** the project-lib instances are best-effort parsing/cleanup fallbacks; none sit on a security decision path.

## Residual risk / not changed (by design or by policy)
- `lib_bejson_Core_bejson_env.py:52` uses `exec()` to source the user's env file (bandit B102). Core libraries are frozen; the file is the user's own and is not model-writable through any action tag that bypasses the path guard. Flagged, not modified.
- `/api/exec` and `/api/files/browse` are intentionally unrestricted for the token holder (personal admin tool). The token, loopback bind, Host check and `--allow-remote` gate are the controls.
- `http_get` can still reach loopback/private (non link-local) hosts; blocking them would break local-dev fetches. Add an allowlist setting if you want that tightened.
- Every key that ever appeared in a pre-pkg120 log should still be considered exposed and rotated.
